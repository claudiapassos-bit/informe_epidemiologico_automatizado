# informe_epidemiologico_automatizado

**Informes Epidemiológicos Automatizados para Vigilância de Arboviroses com RStudio**

Este projeto consiste no desenvolvimento de uma solução automatizada para a geração de Informativos Epidemiológicos de Arboviroses, integrando a extração, o processamento de dados e a diagramação de relatórios gerenciais para o apoio à tomada de decisão na saúde pública.

A iniciativa visa mitigar processos manuais e repetitivos na consolidação de boletins semanais ou quinzenais, conectando diretamente as bases de dados de monitoramento (como e-SUS VS e GAL) a scripts de análise estatística e geração de documentos padronizados.

Principais entregas e funcionalidades:Pipeline de Automação de Dados: Rotinas computacionais (via RStudio) para cálculo automático de indicadores epidemiológicos essenciais, como incidência, taxa de positividade laboratorial, distribuição por faixa etária e espacialização de casos de Dengue, Zika e Chikungunya.

Geração Dinâmica de Relatórios: Produção automatizada de gráficos, tabelas e mapas temáticos atualizados a cada ciclo de fechamento de dados.

Agilidade na Divulgação de Alertas: Redução expressiva no tempo de entrega dos boletins epidemiológicos às equipes técnicas, gestores e unidades de saúde, garantindo maior transparência e rapidez na resposta a potenciais cenários de surto.

Padronização Técnica: Manutenção de um layout institucional consistente, alinhado às diretrizes de vigilância em saúde e pronto para publicação ou circulação interna.
